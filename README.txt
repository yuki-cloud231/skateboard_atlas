滑板网站 GitHub 上传包

1. 解压 ZIP，双击 index.html 可在本地预览。
2. 仓库 → Add file → Upload files。上传解压后的全部文件及 assets 文件夹。
3. 确保 index.html 直接位于仓库根目录，不要直接上传 ZIP，也不要套一层文件夹。
4. 点击 Commit changes。
5. Settings → Pages → Deploy from a branch → main → /(root) → Save。
6. 等待部署完成，打开 Pages 显示的网站链接。

关注记录保存在当前浏览器，换设备或换网址不会自动同步。
